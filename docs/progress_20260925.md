## 2. 結果

動作点（特記なきものは共通）：[[72,12,6]]、X 基底、circuit-level、T=6 ラウンド（測定 8 ラウンド）、
p=0.004、SNR=8.4、β=0.05（p_S,avg=0.032）、p_leak=0.005・p_seep=0.2（定常リーク率 ρ=2.45%、平均持続長 5）、
**同一 2000 ショット（seed=0）**、後段 BP-OSD は `schedule="serial"`, max_iter=200, osd_order=7。

### 2.1 シミュレータの健全性（T1-6 関門、リーク無し）

| | LER | CP95% | BP 収束 |
|---|---|---|---|
| 参考：IQ 雑音なし | 0.016 | [0.011, 0.023] | 0.635 |
| B0 hard | 0.166 | [0.150, 0.183] | 0.076 |
| B1 soft | **0.077** | [0.065, 0.089] | 0.199 |

soft が hard の **2.2 倍**（対応のある比較：B0 だけ失敗 221 / B1 だけ失敗 43）。既知事実の再現に成功。
検出器は測定記録ベースで DEM サンプラと厳密一致。IQ 分布は Riverlane 式(7)(8) と最大差 < 0.01。

### 2.2 ベースライン群（リークあり、T2-2）

| | LER | CP95% | BP 収束 | レイテンシ 中央値 / p99 |
|---|---|---|---|---|
| B0 hard | 0.278 | [0.258, 0.298] | 0.009 | 6.33 / 6.74 s |
| B1 soft | 0.159 | [0.143, 0.176] | 0.043 | 6.36 / 6.80 s |
| B2 Hanisch 円形境界 → p_s=0.5 | 0.172 | [0.156, 0.189] | 0.039 | 6.36 / 6.82 s |
| B3 MAP 判定 → p_s=0.5 | 0.159（**≡ B1**） | — | 0.043 | 6.36 / 6.79 s |
| B3s Bayes 最適 per-shot p_S | 0.162 | [0.146, 0.178] | 0.046 | 6.40 / 6.85 s |
| **ORC** 真の ℓ → p_s=0.5 | **0.106** | [0.093, 0.120] | 0.103 | 6.31 / 6.77 s |

**この表が本研究の出発点になる 3 つの事実**：

1. **per-shot のリーク処理は何も足さない。** B3（MAP 判定）は ρ<5% では判定領域が空集合になり
   **一度も発火しない（B3 ≡ B1）**。B3s（判定を経ない Bayes 最適）も B1 と差なし（83, 88）。
   → 「1 点からのリーク判別は原理的に弱い」。既存手法の前処理（$p_s{=}0.5$）に理論的根拠がない、という
   Hanisch / Riverlane の指摘を、**弱いのではなく効果が 0 である**形で定量化できた
2. **B2（Hanisch 流）は害。** 適合率 2.7% / 再現率 0.8% のフラグで正常測定を捨てて B1 より悪化（43, **69**）
3. **オラクルは B1 から 1/3 削る**（0.159 → 0.106）。**古典側に残っている余地は 0.053** で、
   per-shot 手法はその 0% を取っている。ここが本研究の標的

### 2.3 学習型デコーダ end-to-end（T3、20 万 step）

| | 表現 | 時間方向 | LER | CP95% | リーク P/R/AUC | 推論 GPU / CPU（batch=1 中央値） |
|---|---|---|---|---|---|---|
| ① r1_raw_seq | raw 576×(I,Q) | あり | 0.417 | [0.395, 0.439] | 0.82 / 0.55 / **0.973** | 0.71 ms / 5.3 ms |
| ② r2_hard_seq | hard 504 | あり | 0.515 | [0.492, 0.537] | 0.64 / 0.11 / 0.867 | 0.66 ms / 5.0 ms |
| ③ r3_soft_seq | soft 504 | あり | 0.375 | [0.354, 0.397] | 0.78 / 0.43 / 0.952 | 0.66 ms / 5.0 ms |
| ④ r4_raw_single | raw | **なし** | 0.898 | [0.884, 0.911] | 0.71 / 0.01 / 0.872 | 0.89 ms / 7.0 ms |
| 比較：B1 | | | 0.159 | | | 6.3 s |
| 比較：B4（HMM） | | | | | — / — / 0.958 | |

- **end-to-end では BP-OSD に遠く及ばない**（0.375 対 0.159）。train LER ≈ val LER で過学習ではなく、
  20 万 step でも曲線は緩く下降中 → **容量不足か最適化の遅さ**（d=128・6 層、1.29M パラメータは小さい）
- 順位は **soft > raw > hard**。**「潰さない」は end-to-end では出ていない**（raw が soft に負ける）
- ただし**リークヘッドは raw 系列が最良で、古典最適の時間推論 B4（AUC 0.958）を超える**（0.973）。
  → 「潰さない」ことの利得は**論理誤り予測ではなくリーク推論に現れている**。これが hybrid の根拠
- リーク P/R は raw（測定単位の教師、正例 2.4%）と soft/hard（検出器 OR 教師、2.9%）で教師が違うため
  厳密な横並びではない（AUC も同様。脚注が必要）

### 2.4 hybrid による機構の分離（T4-2、本研究の主要結果）

リーク推論の情報源だけを差し替え、**後段はすべて BP-OSD** に固定（学習型のリーク確率 → $p_S$ → BP-OSD）。

| リーク推論の情報源 | LER | CP95% | 使う情報 |
|---|---|---|---|
| B1（1 点 soft） | 0.1590 | | なし |
| B3s（1 点 Bayes 最適） | 0.1615 | | なし |
| **B4**（HMM） | **0.1345** | [0.120, 0.150] | 時間のみ（量子ビット単独） |
| **hybrid ④**（単発モデル） | **0.1405** | [0.126, 0.157] | 空間のみ（同一ラウンド 72 量子ビット） |
| **hybrid ①**（系列モデル） | **0.1245** | [0.110, 0.140] | **時間 × 空間** |
| ORC（真のリーク） | 0.1060 | | — |

対応のある比較（左だけ失敗, 右だけ失敗）と正確二項 p 値：

| 比較 | (左, 右) | p 値 | 読み |
|---|---|---|---|
| hybrid ① vs B1 | (78, 147) | 5e-6 | **1 点判別に有意に勝つ。オラクルの余地 0.053 の 65% を回収** |
| hybrid ① vs hybrid ④ | (70, 102) | 0.018 | **時間方向の寄与 0.016（有意）** |
| hybrid ④ vs B3s | (53, 95) | 0.0007 | **空間方向＝符号構造の寄与 0.021（有意）** |
| hybrid ① vs B4 | (59, 79) | 0.10 | 時間のみの古典最適に方向は勝つが有意でない（1 万ショット要） |
| hybrid ④ vs B4 | (93, 81) | 0.40 | 空間のみと時間のみは同程度 |
| hybrid ① vs ORC | (63, 100) | 0.005 | オラクルにはまだ有意に届かない |

- **単発 ④ のリークヘッドは閾値 0.5 では再現率 0.014 だが、確率のまま渡すと効く。**
  B3 が退化し B3s が効くのと同じ教訓（判定するな、確率で渡せ）
- 計画書の「① vs ④」は end-to-end では成立しなかったが、**hybrid では成立した**

## 3. 論文の主張として固まったこと

1. **既存の per-shot リーク前処理は効果が 0（B3 ≡ B1）、円形境界は有害（B2 > B1）。** ← 定量化できた
2. **リークの所在が分かれば古典デコーダでも LER を 1/3 削れる（0.159 → 0.106）。** ← 標的の大きさ
3. **学習型は時間方向と空間方向の両方でリーク推論を改善し、その余地の 65% を回収する（0.1245）。**
   時間 0.016（p=0.018）、空間 0.021（p=0.0007）と**両方が有意**。← 主要主張
4. **「潰さない」の利得はリーク推論に現れる（AUC raw 0.973 > soft 0.952 > hard 0.867）。**
   論理誤り予測（end-to-end）には現れない
5. **レイテンシは秒 vs ミリ秒。** ただしテール発散の主張は取り下げる

## 4. 計画から修正した点（重要）

| 計画の記述 | 実測でどうなったか |
|---|---|
| 「soft 化でショットごとのグラフ更新でさらに遅くなる、p99 = 114 秒」 | **再現しない**（B0 6.33 / B1 6.36 s、p99 も 1.07 倍）。「秒オーダー（OSD 支配）vs 約 1 μs の予算」に書き換え |
| 「(ii) soft-collapsed が古典の上限」 | **言い過ぎ**。測定ごとの $p_S$ を事前確率に入れる限り損失なし（B1 / B3s が最強の古典比較対象） |
| 「B3 が本当の対戦相手」 | B3 は退化。**B3s に読み替え**。ただし B3s も B1 と差なし |
| 「soft-raw は 648 測定」 | **576**（データ最終読み出し 72 はラベルそのもの＝入力に入れると漏洩） |
